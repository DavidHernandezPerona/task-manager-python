# Task Manager Python

Aplicación de gestión de tareas desarrollada en Python.

## Demo Online

https://david-task-manager.streamlit.app/

## Descripción

Proyecto desarrollado para practicar conceptos fundamentales de programación en Python y control de versiones con Git y GitHub.

## Tecnologías utilizadas

- Python
- Streamlit
- Git
- GitHub

## Conceptos trabajados

- Funciones
- Listas
- Diccionarios
- Ficheros de texto
- Validación de datos
- Persistencia de información

## Funcionalidades

- Añadir tareas
- Ver tareas
- Marcar tareas como completadas
- Volver tareas a estado pendiente
- Editar tareas
- Eliminar tareas
- Buscar tareas
- Mostrar tareas pendientes
- Mostrar tareas completadas
- Borrar todas las tareas
