#Gestor de Tareas en Python

https://david-task-manager.streamlit.app/

##Proyecto realizado para practicar:

- Diccionarios
- Ficheros de texto

- Añadir tareas
- Ver tareas
- Marcar tareas completadas
- Eliminar tareas
- Buscar tareas
- Mostrar pendientes
- Mostrar completadas
- Editar tareas
- Borrar todas las tareas
